# Archive: early Beekeeper drafts (not kept up to date)

These are the early design drafts (Gemini's README, game bible, CSVs and web prototype,
plus the UI spec and HTML mockups). Archived by Leah's decision on 2026-11-07. They are
**not maintained** and disagree with the game in places (for example the 500-bee hive limit,
which v3 removed).

What is current instead:
- `../EARLY_LOOP_RULES.md`: the rules and numbers on paper
- `../LONG_TERM_DESIGN.md`: where the game is going
- `windows/009-beekeeper/spec.md`, `plan.md`, `tasks.md`: what was built
- `windows/src/SoliBee.Core/Models/BeekeeperConfig.cs`: the numbers in code

Still possibly useful as ideas for later stages: the CSVs on candles, wasps and areas, and
the "Room for later features" and "Phone adaptation sketch" mockups.
