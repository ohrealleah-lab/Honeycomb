Privacy Policy

Honeycomb Card Suite — Last updated September 5, 2026

Honeycomb Card Suite ("Honeycomb," "the app") does not collect, store, or share any personal information about you. This policy explains exactly what the app does and does not do.

No accounts, no data collection

Honeycomb has no user accounts, no sign-in, and no analytics or advertising SDKs of any kind. The app does not know who you are and has no way to identify you.

What's stored, and where

Game preferences, saved progress, statistics, and any custom card backs, face art, or backgrounds you import are stored locally on your device only, inside the app's own sandboxed storage. None of this data ever leaves your device, and we have no access to it.

Network access

The only network request Honeycomb ever makes is a manual, user-initiated "Check for Updates" action available from the app's About screen. When you tap it, the app sends a single request to GitHub's public releases API to see if a newer version exists. This request includes only a generic app identifier in the User-Agent header — no personal information, device identifiers, or usage data of any kind is sent. This check never runs automatically or in the background.

Children's privacy

Because Honeycomb collects no data from anyone, it does not collect data from children either.

Changes to this policy

If this policy ever changes, the updated version will be posted at this same URL with a revised date above.

Contact
