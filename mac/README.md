# 🐝 Honeycomb Card Suite — macOS

## ♦️ Getting Started

### Prerequisites
* **Operating System**: macOS 14.0 or later
* **Compiler**: Swift 6 / Swift 5.10 (Xcode 15+ Command Line Tools installed)

### Build Commands
Run these from the `mac/` folder. A simple `Makefile` handles compiling, packaging a standalone `.app` bundle, testing, and running:

* **Compile the application**:
  ```bash
  make build
  ```
  *Creates a standalone, double-clickable `Honeycomb.app` bundle in `mac/`.*

* **Build & run Honeycomb**:
  ```bash
  make run
  ```

* **Execute the unit test suite**:
  ```bash
  make test
  ```

* **Clean build artifacts**:
  ```bash
  make clean
  ```

## 📁 Repository Structure

```text
mac/
├── Honeycomb.app/          # Native standalone macOS bundle (generated by make build)
├── Makefile                # build / run / test / clean
├── SoliBeeTests/           # Unit tests for game state, scoring, casino logic, and the Honeycomb card database
├── specs/                  # Specifications & plan files
└── src/                    # macOS-only code
    ├── SoliBeeApp.swift    # App entry point
    ├── Models/             # Custom backgrounds, card backs, face-card art, update checker
    ├── Views/              # App router, shared views
    ├── Honeycomb/          # Honeycomb card battle views
    ├── Beecell/            # Freecell views
    ├── Spider/             # Spider views
    ├── Blackjack/          # Blackjack views
    └── VideoPoker/         # Video Poker views
```

The game logic (models and view models) is shared with iOS and lives in `../shared/`.
